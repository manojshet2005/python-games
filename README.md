# Snake Water Gun Game Using Python

A simple command-line Snake, Water, Gun game written in Python. You play against the computer, which randomly chooses one of the three options.

## Requirements

- Python 3

## Run the game

Open a terminal in this folder and run:

```powershell
python snake_water_gun_game.py
```

When prompted, enter:

- `s` for snake
- `w` for water
- `g` for gun

## Rules

- Snake beats water.
- Water beats gun.
- Gun beats snake.
- Matching choices result in a tie.
